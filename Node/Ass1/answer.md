**Q1 ROLE OF FRONTEND**

![Web Application Architecture](https://upload.wikimedia.org/wikipedia/commons/5/5f/Client-server-model.svg)
The Frontend is the part of a web application that users directly see and interact with in the  browser.
### User Interface
Frontend is responsible fro designing the user Interface.It inculde layouts,buttons,forms,text,colors,and images that make tha application visually clear and user-friendly.
### User Interaction
Frontend handles all user actions such as clicking buttons,submitting forms,navigating pages, and showing alerts or error messeges.
### Communication with Backend
Frontend communicates with the backend wsing APIs. It sends user data to the server and displays the response received from the backend.
